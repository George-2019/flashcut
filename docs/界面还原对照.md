## AI 能力

| 能力 | 实现方式 |
|---|---|
| 镜头切分 | 本地抽帧（每 1.2 秒一帧），相邻帧亮度差 > 26 判定切镜 |
| 画面打分 | 32×32 缩放后相邻像素差（清晰度）+ 亮度，映射到 20–99 分 |
| 剪辑脚本 | WorkBuddy（本机 `10.66.11.69:8791`）生成 JSON EDL |
| 降级 | 大模型不可用 → 按分数取前 N 个镜头拼到目标时长 |
| 精剪 | 分割、变速（1×/2×）、删除，改动实时存工程 |
