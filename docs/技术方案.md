# 闪剪 FlashCut · 技术实现方案（端云混合 v0.2）

> 目标：手机端输入多段视频，大模型理解内容 → 提取高光 → 多段合成 → 自动套特效模板 → AI 解说词 + TTS 配音 + 配乐 → 自动字幕 → 可精剪细剪 → 导出。
> 已定方向：**端云混合**（本地分析 + 云端大模型决策）、**AI 解说词 + TTS 配音**、首批模板 **旅行 Vlog / 情绪卡点**。

---

## 1. 总体架构

```
┌────────────────────────── Android App ──────────────────────────┐
│  素材层    相册多选 / 文件 / 分享导入 → MediaExtractor 元数据校验    │
│  分析层   镜头切分 · 画质打分 · 人脸/主体检测 · VAD · ASR（sherpa-onnx）│
│  决策层   → HTTP → 大模型服务：剪辑脚本 JSON（EDL）                 │
│  包装层   模板参数 + LUT/转场/动效 + TTS 配音 + 曲库 + 字幕排版       │
│  合成层   Media3 Transformer 逐段渲染 → 拼接 → 混音 → 硬编导出      │
│  精剪层   多轨时间线 UI（视频/字幕/旁白/音乐/特效）→ 局部重渲染         │
└──────────────────────────────────────────────────────────────────┘
             ↑ 只上传：字幕文本、镜头标签、缩略图        ↑ 不传完整视频
```

**关键原则**：大模型只做"决策"，不做"渲染"。它输出的是可编辑的时间线（EDL JSON），渲染由端上拿到参数后用 MediaCodec 完成，这样既有 AI 的"眼光"，又保持实时预览和二次精修能力。

## 2. 各环节实现

### 2.1 多段素材导入

| 项 | 方案 |
|---|---|
| 选择 | `PickMultipleVisualMedia`（Android 13+ Photo Picker，免存储权限） |
| 导入 | `ContentResolver` 拿 `content://` URI，不复制原片 |
| 元数据 | `MediaMetadataRetriever`：时长、分辨率、旋转、码率、HDR |
| 预处理 | 非 16:9/9:16 统一转成"画布 + 缩放/裁切"，避免后续每帧判断 |
| 限制 | 单段 ≤ 10 分钟；总时长 > 4 分钟时提示"分析耗时较长"；4K/HEVC 走硬解 |

### 2.2 内容理解（全部端侧）

| 能力 | 实现 | 输出 |
|---|---|---|
| 镜头切分 | FFmpeg `select='gt(scene,0.3)'` 或 Media3 帧差分析 | 每个镜头 `[start,end]` |
| 画质/稳定性 | 帧差 + Laplacian 清晰度 + 陀螺仪数据 | `sharpness / stability` 0–1 |
| 主体与人脸 | MediaPipe Face/Person Detector，抽样每秒 2 帧 | 人脸框、人物占比 |
| 语音活动 | silero-VAD（ONNX） | 语音段、静音段 |
| 语音识别 | sherpa-onnx + Zipformer 中文模型，带标点 | 带时间戳文本 |
| 场景标签 | MobileCLIP / 轻量分类模型（可选） | 海边/街道/室内/人像 |

> 抽样策略：每秒 2 帧做画面分析，ASR 只处理语音段，避免中端机发热。10 分钟素材端侧分析目标 **< 90 秒**。

### 2.3 大模型剪辑决策（云端）

**输入（JSON，几十 KB）**

```json
{
  "intent": "30秒旅行Vlog，情绪从期待到放松，保留日落与回头",
  "constraints": {"aspect": "9:16", "duration": 30, "template": "travel_warm", "voice": "ai_female_soft"},
  "clips": [
    {"id": "c1", "start": 0, "end": 8.2, "tags": ["街道", "推镜"], "speech": "今天到了古城...", "quality": 0.82, "thumb": "data:image/jpeg;base64,..."}
  ]
}
```

**输出（EDL）**

```json
{
  "shots": [
    {"clipId": "c1", "in": 0.6, "out": 4.2, "speed": 1.0, "layer": "main",
     "effects": ["push_in", "film_grain"], "transitionIn": {"type": "dissolve", "dur": 0.4},
     "reason": "开场建立地点"},
    {"clipId": "c2", "in": 2.1, "out": 10.1, "speed": 0.85, "effects": ["slow_motion"],
     "reason": "情绪上升，慢放强化"}
  ],
  "narration": [{"start": 0.4, "end": 4.0, "text": "那天傍晚，风从海面吹过来。"}],
  "music": {"trackId": "sunny_days", "bpm": 110, "beatAlign": true, "duckingDb": -8},
  "captions": [{"start": 0.4, "end": 4.0, "text": "出发，去洱海", "style": "bottom_white"}]
}
```

**实现要点**

- 模型用**结构化输出 / Function Calling**，schema 校验失败自动重试 1 次，仍失败则降级到规则剪法；
- 传入缩略图网格（3×3，640px），而不是让模型逐帧"看视频"，控制成本与延迟；
- "换一版"只换 seed 与意图，复用端侧分析缓存；
- 云端只返回参数，不返回像素，保证可撤销、可精修。

### 2.4 多段合成与套模板

| 层 | 实现 |
|---|---|
| 模板 | JSON 描述：镜头节奏区间、转场类型/时长、LUT、字幕样式、音乐 BPM 段 |
| 转场 | 端上用两段 Transformer 输出 + 50 帧叠化/推拉，预渲染缓存 |
| LUT/滤镜 | `GlEffect` 自定义 3D LUT，走 GPU（OpenGL/MediaCodec 纹理） |
| 动效 | 推镜/放大用 `Presentation` 的缩放矩阵，关键帧插值 |
| 切点对齐 | 以音乐 beat 网格为基准，允许 ±0.3 秒吸附 |

首批两套：
- **旅行 Vlog（暖色）**：4–6 秒长镜头、叠化、胶片颗粒、字幕底部白字黑边；
- **情绪卡点（强节拍）**：0.8–2 秒快切、强对比、闪白/缩放冲击、字幕大字强调。

### 2.5 配音与配乐

| 项 | 方案 |
|---|---|
| 解说词 | 与剪辑脚本同一次大模型返回，保证"画面—文案"对应 |
| TTS | 云端高质 TTS（情感女声/男声）为主，端侧 sherpa-onnx TTS 做离线降级 |
| 时长控制 | TTS 后按实际音频长度回写 EDL，必要时微调镜头时长 |
| 配乐 | 可商用曲库 + BPM 标签；本地"节拍检测"用于非曲库音频 |
| 混音 | 旁白轨为主，音乐自动闪避（ducking）−8 dB，原声按 EDL 开关 |

### 2.6 字幕

1. 有旁白 → 直接使用旁白文本按 TTS 边界打轴；
2. 有原声 → ASR 时间戳 + 标点重建，句长超过 14 字自动断句；
3. 双语 → 原声 ASR + 翻译（可选）；
4. 导出附带 SRT，方便二次使用。

### 2.7 精剪与渲染

- **数据结构**：`Project → Tracks[] → Clips[] → Effects[]`，每条 clip 保存原片 `in/out`，非破坏式；
- **预览**：Media3 `ExoPlayer` + 自定义 `GlEffect` 实时预览；
- **导出**：`Transformer` 按轨道合成，视频 `h264_mediacodec`，失败回退 `h265` → 软编；
- **局部重渲染**：只重渲染改动片段，再拼接，避免每次全片重导；
- **精剪粒度**：播放头吸附、片段分割、帧级微调（±1 帧）、多轨拖拽、关键帧曲线。

## 3. 数据模型（核心）

```kotlin
data class Project(
  val id: String, val aspect: AspectRatio, val fps: Int,
  val sources: List<Source>, val tracks: List<Track>,
  val template: TemplateRef?, val narration: Narration?, val music: MusicRef?
)
data class Source(val uri: Uri, val durationUs: Long, val features: SourceFeatures)
data class Track(val type: TrackType, val clips: List<Clip>)   // VIDEO / CAPTION / VOICE / MUSIC / FX
data class Clip(val srcId: String, val inUs: Long, val outUs: Long,
                val speed: Float, val effects: List<EffectRef>, val reason: String?)
```

工程序列化为 `.fcpj`（zip + JSON + 缩略图），可直接上传/备份。

## 4. 性能预算（中端机：骁龙 7 系）

| 环节 | 目标 | 兜底 |
|---|---|---|
| 导入 4 分钟素材 | < 10 秒 | 后台导入 |
| 端侧分析 | < 90 秒 | 降采样、只分析语音段 |
| 大模型决策 | < 8 秒 | 超时 15 秒回退规则剪法 |
| TTS 18 秒旁白 | < 6 秒 | 端侧 TTS |
| 1080P/30 导出 30 秒 | < 60 秒 | 720P、降帧率 |
| 内存峰值 | < 800 MB | 分段渲染、流式合成 |

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 大模型返回不合规 EDL | 成片错乱 | JSON Schema 校验 + 失败重试 + 规则降级 |
| 云调用费/延迟 | 体验差 | 一次调用产出全部决策；缓存分析结果；小模型做初筛 |
| ASR 中文准确率 | 字幕错 | 端侧模型选 Zipformer 中文版；支持一键全文编辑 |
| FFmpeg 体积与许可 | 上架/包体 | 只用于镜头切分与复杂滤镜；商用仅 LGPL 组件 |
| 4K/HDR 兼容 | 花屏/偏色 | HDR 转 SDR 预览，导出保留 SDR |
| 模板同质化 | 用户流失 | 模板只定"风格"，内容与镜头由素材决定 |
