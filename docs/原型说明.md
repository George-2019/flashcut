# 闪剪 FlashCut · 原型说明（v0.2 全链路）

> 交互文件：`prototype/index.html`（单文件、无外部依赖、可离线打开）。
> v0.1 简版保留在 `prototype/v01-简版-index.html`，用于对比。

## 1. 定位

手机端全链路智能剪辑：**多段素材输入 → 大模型理解内容 → 提取高光 → 多段合成 → 自动特效与模板 → AI 解说词 + TTS 配音 + 配乐 → 自动字幕 → 多轨精剪细剪 → 导出**。

已确认方向：

- **端云混合**：视频解码、镜头分析、ASR 在本地；云端大模型只接收文本与缩略图，返回剪辑脚本。
- **配音**：AI 解说词 + TTS 人声，同时保留原声。
- **首批模板**：旅行 / 生活 Vlog、情绪卡点 / 燃向混剪。

## 2. 主链路（11 屏）

`首页 → 多段导入 → AI 理解素材 → 理解结果 → 剪辑脚本 → 模板特效 → 配音配乐 → 字幕 → 成片预览 → 精剪 → 导出`

另有模板中心、项目管理、隐私设置 3 个辅助页，共 **14 屏**。

## 3. 逐屏说明

| # | 页面 | 关键内容 | 设计意图 |
|---|---|---|---|
| 01 | 首页 | 主入口、四种成片类型、本地能力自检、上次项目 | 先让用户选"剪什么"，决定后续模板与节奏 |
| 02 | 多段导入 | 缩略图多选、多来源导入、去重/排序开关 | 明确支持多段；单段/总长限制提前告知 |
| 03 | AI 理解素材 | 端云分工说明、5 个分析步骤、进度 | 让"隐私"变成可感知的产品卖点 |
| 04 | 理解结果 | 主题、置信度、高光镜头评分、语音要点 | AI 结论可见、可质疑，作为"喂给大模型的证据" |
| 05 | 剪辑脚本 | 一句话指令、镜头表（入出点/用途/特效/转场）、预计参数 | 核心交互：用户审"脚本"而不是审"黑盒视频" |
| 06 | 模板与特效 | 3 套模板卡、LUT/稳定/速度曲线/转场开关 | 模板是参数组合，不是固定画面 |
| 07 | 配音与配乐 | TTS 音色/语速、AI 解说词逐句改、候选音乐、闪避开关 | 解决"配音"诉求，并把版权风险前置 |
| 08 | 字幕 | 逐条文本 + 时间轴编辑、4 种样式、断句/高亮 | 字幕是精修高频入口，必须可批量改 |
| 09 | 成片预览 | 竖屏播放器、AI 做了什么的解释卡、指标 | 先给结果，再给修改入口 |
| 10 | 精剪时间线 | 5 轨（视频/字幕/旁白/音乐/特效）、帧级提示、AI 精剪建议 | 满足"精剪细剪"；AI 建议可接受/忽略 |
| 11 | 导出 | 分辨率/帧率/编码/音量归一化、工程与 SRT 一并保存 | 本地导出、无水印、可继续编辑 |
| 12 | 模板中心 | 旅行高光、情绪燃剪、电影叙事等 | 首批聚焦两类，其余延后 |
| 13 | 项目管理 | 编辑中 / 已导出 / 脚本待确认 | 验证工程持久化概念 |
| 14 | 我的 / 隐私 | 上传内容清单、完整视频从不上传、Wi-Fi 开关 | 把 AI 数据边界做成用户能看懂的设置 |

## 4. 精剪能力的范围

**本期原型包含**：多轨拖拽、片段选中、分割、变速、特效、音频面板、AI 建议对齐、帧级时间码显示。

**真正上线需要补齐**：

- 双指缩放时间线、磁性吸附、波纹删除、插入/覆盖模式
- 关键帧曲线（缩放、位移、透明度）
- 画中画 / 蒙版 / 绿幕
- 撤销栈（至少 50 步）与工程版本历史
- 局部重渲染（只重渲改动的片段）

## 5. 核心数据流

```
素材 URI + 元数据
   ↓ 端侧分析（镜头、画质、人脸、VAD、ASR）
AnalyzResult（字幕、镜头列表、特征分、缩略图）
   ↓ 只上传文本与缩略图
大模型 → EDL JSON（镜头顺序、入出点、特效、旁白、字幕、配乐）
   ↓ 端上应用模板
Project（多轨 Clip）
   ↓ Media3 Transformer
MP4 + 工程 .fcpj + SRT
```

## 6. 原型交互验证结果

- 14 个页面全部存在，导航目标无失效
- 主链路 10 次跳转全部通过（01→02→…→11）
- 多选素材数量同步
- 分析进度自动推进并进入结果页
- 导出进度 0→100%，完成后显示分享卡片
- 模板/字幕样式/开关/片段选中均有选中态
- 底部导航与"原型导航"均可跳转

## 7. 下一步优先级

1. **先验证脚本页**：用户是否愿意读 4 条镜头的"剪辑脚本"再生成？这是整个产品的信任基础。
2. **再验证精剪深度**：普通用户会打开时间线吗？如果不会，AI 建议要更主动。
3. **模板扩展**：跑通旅行 Vlog 后，情绪卡点的节拍检测是最大的技术不确定项。
