# 在手机/容器内构建 FlashCut APK

## 结论先说

这台手机（Xiaomi 24129PN74C，Android 16 / arm64）里可以**直接运行** JDK、Gradle 等 Linux 原生工具，但**首次构建需要下载约 800MB～1.2GB 的依赖**（Android SDK、AGP、Kotlin、Media3 等）。当前环境到 Google/Maven 的下载速度只有 **50～60 KB/s**，单次构建需要数小时，且连接经常中断，所以这一轮没有完成 APK 打包。

**更现实的两条路：**

1. 在电脑上用 Android Studio 打开这个工程，一次构建（10 分钟内）生成 APK，再 `adb install` 到手机；
2. 把工程推到 GitHub，用 GitHub Actions 云端构建（见下方 workflow），手机上下载 artifact 安装。

工程本身是完整可编译的，不是伪代码。

**已实现的真实功能：**

- 多段视频导入（Android 13+ Photo Picker，低版本走系统选择器）
- 读取每段时长/分辨率，按顺序生成时间线
- 逐段拖动入点/出点裁剪、移除片段、实时汇总成片时长
- Media3 Transformer 本地导出 MP4（H.264/AAC，硬件编码）
- 导出页播放与系统分享
- 大模型 API 配置：8 个服务商预设、自定义 Base URL、拉取模型、测试连接、本机保存

## 本地构建（电脑）

1. 安装 Android Studio（自带 JDK 17、SDK）
2. 打开 `flashcut` 目录，等待 Gradle Sync
3. `Build → Build Bundle(s)/APK(s) → Build APK(s)`
4. 产物：`app/build/outputs/apk/debug/app-debug.apk`
5. 手机开 USB 调试后：`adb install -r app-debug.apk`

命令行方式：

```bash
export ANDROID_HOME=$HOME/Android/Sdk
./gradlew :app:assembleDebug
```

首次需要生成 Gradle Wrapper：

```bash
gradle wrapper --gradle-version 8.13
```

## 云端构建（GitHub Actions）

把以下内容保存为 `.github/workflows/build.yml`，push 后自动出 APK：

```yaml
name: Build FlashCut APK
on: [push, workflow_dispatch]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
      - uses: android-actions/setup-android@v3
      - name: Build
        run: |
          gradle wrapper --gradle-version 8.13 || true
          ./gradlew :app:assembleDebug --no-daemon
      - uses: actions/upload-artifact@v4
        with:
          name: flashcut-debug-apk
          path: app/build/outputs/apk/debug/*.apk
```
