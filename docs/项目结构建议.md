# 闪剪 FlashCut · 项目结构与改造建议

## 1. 不要从零写：fork 哪个

| 候选 | 许可 | 能用的部分 | 需要补的 | 结论 |
|---|---|---|---|---|
| [LibreCuts](https://github.com/tharunbirla/LibreCuts) | MIT | 时间线、叠加、关键帧、字幕、音频、硬件导出、工程文件 | AI 决策、端侧分析、模板系统 | **首选底座**，可商用 |
| [open-video-editor](https://github.com/devhyper/open-video-editor) | GPL-3.0 | Media3 + Compose 的干净参考 | 几乎全部 AI 能力 | 只当参考代码，别 fork（GPL 传染） |
| [EpMedia](https://github.com/yangjie10930/EpMedia) | MIT | FFmpeg 命令封装 | 已停更、NDK 老旧 | 只抄命令拼装思路 |

**建议：以 LibreCuts 的逻辑与交互为底，新建 clean 工程重写核心层，把 FFmpeg 收窄到"镜头切分 + 特殊特效"，其余用 Media3。** 直接改 fork 历史会拖慢重构；保留其 LICENSE 声明即可。

## 2. 目标工程结构（Gradle 多模块）

```
flashcut/
├── app/                       # 壳工程：导航、权限、DI
├── core/
│   ├── model/                 # Project / Track / Clip / EDL（纯 Kotlin）
│   ├── media/                 # Media3 封装：解码、Transformer 渲染、导出
│   ├── analysis/              # 镜头切分、画质打分、VAD、ASR（sherpa-onnx）
│   └── project/               # .fcpj 工程序列化、自动保存
├── feature/
│   ├── import/                # 多段素材选择与导入
│   ├── brief/                 # 理解结果确认
│   ├── script/                # 大模型脚本展示与重生成
│   ├── template/              # 模板预览与参数
│   ├── voice/                 # TTS、解说词、配乐选择
│   ├── subtitle/              # 字幕编辑
│   └── timeline/              # 多轨精剪
├── ai/
│   ├── cloud/                 # 大模型 EDL 请求、Schema 校验、重试
│   └── ondevice/              # sherpa-onnx、MediaPipe 推理封装
├── design/                    # Compose 主题、图标、动效
└── docs/
```

## 3. 关键接口（伪代码）

```kotlin
interface ClipAnalyzer {
    suspend fun analyze(sources: List<Source>): AnalyzeResult
}

interface EditPlanner {
    suspend fun plan(intent: Intent, analysis: AnalyzeResult): Edl
}

interface Renderer {
    suspend fun export(project: Project, options: ExportOptions): ExportResult
}

interface VoiceSynthesizer {
    suspend fun synthesize(lines: List<NarrationLine>, voice: VoiceId): List<VoiceClip>
}
```

**约束**：`ai` 模块不得直接操作视频像素；`core:media` 不得依赖 `ai`，保证离线可用与可测试。

## 5. 分阶段里程碑

### M1（2 周）跑通导出

- 多段导入 → 简单拼接 → Media3 导出 MP4
- 工程保存与恢复
- 验收：4 段素材 30 秒成片可导出到相册

### M2（2 周）端侧理解

- 镜头切分、VAD、ASR、画质打分
- 分析结果缓存
- 验收：4 分钟素材分析 < 90 秒，返回可展示的镜头列表

### M3（1 周）云端决策

- EDL Schema + Prompt + 校验重试
- 脚本展示页
- 验收：同一素材可稳定产出 4–6 镜头方案，非法 EDL 自动降级

### M4（2 周）包装能力

- 旅行 Vlog 模板、LUT、转场、字幕样式
- TTS 配音、曲库、闪避混音
- 验收：一键成片效果接近原型第 9 屏

### M5（2 周）精剪

- 多轨时间线、分割、变速、帧级微调
- 局部重渲染
- 验收：修改单个片段后 10 秒内重新导出

### M6（1–2 周）第二套模板

- 情绪卡点模板、节拍检测、强特效
- 性能调优与内测

## 6. 测试清单

- [ ] 相册选 10 段（含 HEVC/4K/竖拍）导入不崩
- [ ] 无网络时能完成"本地规则剪辑 + 端侧 TTS + 导出"
- [ ] 大模型超时/返回非法 JSON 时可降级
- [ ] 长视频（>10 分钟）切段处理不 OOM
- [ ] 精剪后导出与预览逐帧一致
- [ ] 切后台导出不中断，通知显示进度
- [ ] 不同 DPI/比例设备上模板画面不出黑边
- [ ] 工程文件往返序列化无数据丢失
